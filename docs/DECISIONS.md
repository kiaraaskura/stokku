## Technical defaults (recommended, not frozen)

- API: `axum 0.8`, `tokio`, `sqlx 0.8` **runtime queries**, `tower-http` (trace, cors, limit), `tracing`, `argon2`, `jsonwebtoken`, `uuid` v7. One binary. Config by env.
- Web: Vite + React 19 + TypeScript, React Router, plain CSS with tokens (no UI kit), `zod` at the edges, `@tanstack/react-virtual` for long lists, local SQLite via `sql.js`/OPFS or `wa-sqlite` for the web shell — pick one and record it in `apps/web/README.md`.
- Shared: TypeScript DTOs generated by hand from `API_CONTRACT.md` in `packages/shared`; Rust mirrors them in `services/api/src/dto.rs`.
- IDs: UUIDv7 everywhere, client-generated for ops.
- Time: store UTC, render in outlet timezone; never trust the client clock for ordering.
- Money: integer rupiah, no floats anywhere, `Math.round` only at the MDR boundary.
- Auth: access 15 min, refresh 30 days rotating, tokens in OS keychain on shells; web shell uses memory + refresh cookie fallback, documented.

## Scope guard

Not in this build, even if it looks easy: multi-outlet, transfers, batch/expiry, thermal printing, marketplace sync, e-Faktur, double-entry, AI reorder, public API, web storefront, dynamic QRIS. If a member starts one, the Captain stops it.
